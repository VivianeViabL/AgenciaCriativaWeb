📱 **Agência Criativa Web** 🎨

Projeto desenvolvido com fins de estudo para praticar técnicas com foco em desenvolvimento Front-End, aplicando conceitos de Design Responsivo utilizando HTML5 e CSS3.

Para um bom funcionamento da responsividade do site, foram utilizadas Unidades Relativas (rem, %, vw, vh), Flexbox, CSS Grid e Media Queries (@media).

Conta também com funções como o botão de Tema (claro/escuro) sendo utilizado o LocalStorage para guardar de forma persistente a preferência do Tema pelo usuário; e Carrossel de depoimentos com transição automática em JavaScript.
