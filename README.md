📱 **Agência Criativa Web** 🎨

Projeto desenvolvido com fins de estudo para praticar técnicas com foco em desenvolvimento Front-End, aplicando conceitos de Design Responsivo utilizando HTML5, CSS3 e SASS (SCSS)

Para um bom funcionamento da responsividade do site, adaptando a interface para diferentes tamanhos de tela, foram utilizadas Unidades Relativas (rem, %, vw, vh), Flexbox, CSS Grid e Media Queries (@media).

Os estilos foram organizados utilizando SASS, com uso de variáveis, mixins, aninhamento e arquivos parciais, seguindo a metodologia BEM para a estruturação das classes.

O projeto também contém funções como o botão de Tema (claro/escuro) sendo utilizado o LocalStorage para guardar de forma persistente a preferência do Tema pelo usuário; e Carrossel de depoimentos com transição automática em JavaScript.
